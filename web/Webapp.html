Refund Calculator

Single-package refund. Non-refundable is TPP plus 20% of the total package cost.

Receipt details

Occupancy packages only. Do not include TPP.

Non-refundable is calculated as TPP + 20% of Total Package Cost.

Instructions

  1. Total Package Cost

    • Enter the cost of occupancy packages only
    • Do NOT include TPP in this total
    • If there are multiple packages, add them together first

  2. Amount Paid

    • Go to the Transaction Summary
    • Locate the line labeled "Amount Paid"
    • Enter that amount

  3. TPP Cost

    • Enter the total cost of the Trip Protection Plan
    • If there are multiple TPPs, add them together before entering

  4. Calculate

    • Click the "Calculate" button
    • The refund amount will appear in the Refund Result panel

Partial Package Refunds

Multi-package receipt. TPP is treated as paid first, then the remaining payment is split across packages in proportion to their price.

Receipt details

Maximum 50.

The non-refundable percentage is calculated separately from each package's own price. TPP is non-refundable per package.

Package prices

Instructions

  1. Number of Packages

    • Enter how many packages are on the booking
    • A box will appear for each package

  2. TPP and Non-Refundable Percentage

    • Enter the TPP amount for one package
    • Enter the non-refundable percentage
    • The percentage is applied separately to each package price

  3. Total Package Price and Amount Paid

    • Total Package Price is what the trip costs in total, from the receipt
    • Amount Paid is what the participant has actually handed over so far
    • Amount Paid is often less than the Total Package Price; that is normal
    • The individual package prices below must add up to the Total Package Price
    • If they do not match, the calculator shows both figures and stops, so check for a mistyped price or a package row left blank

  4. Package Prices

    • Enter each package's price without TPP
    • Number of Packages must match the number of package rows shown
    • If it does not, the calculator names both numbers and stops; re-enter the Number of Packages so the rows match
    • Check the package or packages being removed

  5. Calculate

    • The calculator estimates how much of the total payment belongs to each package
    • It subtracts that package's TPP and non-refundable percentage
    • Only checked package results are shown
    • If more than one package is checked, their refunds are added together at the bottom
